# App Screenshots

Place your app screenshots in this directory.

### Suggested Files

- `dashboard.png` - Main dashboard (zone, plate, city, pay button)
- `alarm.png` - Active parking alarm / countdown timer
- `history.png` - Parking history screen
- `settings.png` - Settings / permissions screen

### Display in README

Once you add screenshots, you can uncomment or update the preview block in the root [README.md](../README.md):

```markdown
<p align="center">
  <img src="screenshots/dashboard.png" width="240" alt="Dashboard" />
  <img src="screenshots/alarm.png" width="240" alt="Alarm" />
  <img src="screenshots/history.png" width="240" alt="History" />
  <img src="screenshots/settings.png" width="240" alt="Settings" />
</p>
```

> **Tip for F-Droid / Fastlane submission**:
> If you publish to F-Droid later, screenshots can also be placed in `fastlane/metadata/android/en-US/images/phoneScreenshots/`.
